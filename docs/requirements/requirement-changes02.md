# 要件定義の変更点

以下に要件定義の変更点を記載する

変更点: 画面上に表示するデータ項目

パート管理表（BPO）CSVファイルのデータ項目一覧に加えて、`必須項目`を表示するようにする。**それ以外の項目は画面上に表示しない。**
その他の仕様は現行のまま変更はない。

## 表示名・呼称の統一

データ項目や表示名に表記ゆれかあるものは以下のように修正・統一する

- 従業員番号、社員番号、従業員ID　→　社員コード
- 時給　→　時給単価

## データベーススキーマの変更

データ項目の追加・変更にともないデータベーススキーマの変更が必要な場合は、変更後の設計と現状との差分を提示する。

## 注意事項
- 現行の仕様で定義されているデータ項目は全て残すこと。
- 同じ内容で表記ゆれがあるものは、この仕様変更にあわせて統一する。
- 指示無くデータ項目を削除することは決して行わない。
